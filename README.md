# Чёрным по белому
Лендинг Frame 1 на Vue 3 и Vite. Запуск: npm ci, затем npm run dev. Статическая сборка: npm run build (каталог dist).
Основные движения — в src/style.css. Покачивание стеблей — анимация wind в public/bamboo.svg; удалите вторую анимацию и вторую задержку, чтобы сохранить только появление. Предпочтение reduced motion учитывается.
Примеры работ вымышлены. Без адреса обработчика форма скачивает локальный текстовый бриф. Для отправки задайте VITE_CONTACT_ENDPOINT в .env.local до сборки; обработчик принимает POST JSON с полями name, contact, project. Перед запуском подключите рабочий обработчик и политику обработки данных.

Во второй версии стебли 31 и 33 вынесены в public/bamboo-front.svg. Настройки движения ветра находятся в обоих SVG. Плавная прокрутка колёсиком использует Lenis; сенсорный скролл остаётся системным. Начальные позиции капель услуг рассчитываются при изменении ширины контейнера. Заголовок использует SVG-фильтр и две CSS-анимации ink-focus и ink-seed.

Для демонстрации лёгкого режима откройте сайт с параметром `?motion=lite`. Он использует неподвижные WebP-слои вместо анимированных SVG. Экономия трафика, медленная сеть, небольшое число потоков/объём памяти и системное сокращение движения выбирают те же изображения до загрузки. Если браузер не сообщает характеристики, учитывается устойчиво низкая частота кадров на первом экране.
